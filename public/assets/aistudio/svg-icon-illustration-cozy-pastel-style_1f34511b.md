# SVG Icon Illustration Cozy Pastel Style

สไตล์ของ Icon และ Illustration **Cozy Pastel Hand-Drawn Vector** หรือ **Cute Japanese/Korean Editorial Infographic Style** (แนวอินโฟกราฟิกการ์ตูนญี่ปุ่น/เกาหลี โทนพาสเทลอบอุ่น) ครับ

หากเจาะลึกลงไปในรายละเอียดเชิงกราฟิก จะมีลักษณะเด่นดังนี้ครับ:

### 1. ลักษณะของเส้น (Line Art / Stroke)

- **เส้นขอบแบบ Filled Outline (มีเส้นตัดขอบและลงสีด้านใน):** เป็นสไตล์เส้นตัดขอบที่มีความหนาปานกลางสม่ำเสมอ แต่ปลายเส้นและมุมจะโค้งมนทั้งหมด ทำให้ดูนุ่มนวลและเป็นมิตร

- **ไม่ใช้สีดำสนิท (Colored / Soft Dark Outlines):** แทนที่จะใช้เส้นสีดำ (`#000000`) ภาพนี้เลือกใช้เส้นสีเข้มที่กลมกลืนกับวัตถุ เช่น สีกรมท่าเข้ม (Dark Slate/Navy) กับพวกอุปกรณ์การแพทย์อย่างหูฟังแพทย์ คลิปบอร์ด หรือกระปุกปัสสาวะ และใช้สีแดงเข้มอมน้ำตาล (Dark Maroon/Brown) กับอวัยวะอย่างไต ตับ หยดเลือด และหลอดเลือด

- **ความรู้สึกแบบวาดมือ (Organic Hand-drawn feel):** รูปทรงไม่ได้เป็นเรขาคณิตเป๊ะๆ แบบ Corporate Icon แต่มีความโค้งมน อ้วนกลม และดูเหมือนวาดด้วยปากกาหัวมน

### 2. โทนสีและการลงแสงเงา (Color & Shading)

- **Soft Pastel & Warm Palette:** ใช้สีพาสเทลที่ลดความสดลง (Muted Pastel) เช่น ชมพูอ่อน แดงคอรัล ฟ้าอมเทา เหลืองนวล และเขียวอ่อน ทำให้เรื่องสุขภาพที่ปกติจะดูเครียด กลายเป็นเรื่องที่ดูผ่อนคลายและอ่านง่ายขึ้น

- **Soft Minimal Shading + White Highlights:** ลงสีพื้นแบบกึ่งแบน (Semi-flat) ผสมกับการปาดเงาอ่อนๆ หรือไล่เฉดสี (Subtle Gradient) เล็กน้อย และมีการแต้มเส้น/จุดไฮไลต์สีขาว (Specular Highlights) บนพื้นผิว เช่น บนหยดเลือด ตับ ไต และกระปุกปัสสาวะ เพื่อให้ดูมีมิติและน่ารักขึ้น

### 3. องค์ประกอบตกแต่ง (Decorative Details)

- **Doodle / Sparkle Accents:** มีการเติมขีดสั้นๆ สีเหลืองส้ม (2–3 ขีด) ไว้รอบๆ ไอคอนแทบทุกจุด เพื่อเพิ่มความมีชีวิตชีวาแบบการ์ตูน (Comic/Doodle style)

- **Sticker-like Aesthetic:** ไอคอนหลายชิ้นดูคล้ายสติกเกอร์ไดคัตที่วางแปะลงบนการ์ดสีพาสเทล

### ทริคหากต้องการเขียนเป็น SVG

หากจะขึ้นโค้ด SVG ให้ได้อารมณ์ใกล้เคียงกับภาพนี้ แนะนำให้ตั้งค่าหลักๆ ดังนี้ครับ:

- กำหนด `stroke-linecap="round"` และ `stroke-linejoin="round"` กับทุก Path เพื่อให้เส้นดูนุ่มและมน
- ใช้สีเส้นขอบเป็นโทนเข้มที่ไม่ใช่สีดำ เช่น `#3B4A6B` (กรมท่าหม่น) หรือ `#7A3238` (แดงน้ำตาลเข้ม) แทน `#000000`
- ใช้ `stroke-width` อยู่ที่ประมาณ `2px` – `2.5px` (บน `viewBox="0 0 64 64"`)
- เพิ่ม Layer ไฮไลต์สีขาว (`#FFFFFF`) ที่ปรับ `opacity="0.6"` และ `stroke-linecap="round"` วาดโค้งตามมุมวัตถุ เพื่อสร้างความเงาแบบน่ารักๆ ครับ
